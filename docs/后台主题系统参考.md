# 后台主题系统参考（设计令牌 + 11 种面板风格）

> 来源：`app/globals.css` + `app/admin/layout.tsx` 主题应用逻辑
> 这是整个后台可主题化的根基，任何新后台项目可直接照搬这套机制。

---

## 1. 机制原理

**一句话**：颜色全部消费 CSS 变量（`--adm-*`），主题 = 换一套变量值；行内样式只要写变量名，就能被 `[data-*]` 属性选择器整体覆写。

```
<html data-admin-panel-style="glass" data-glass-layered="true">
  └─ CSS: [data-admin-panel-style="glass"] { --adm-card: rgba(...); ... }
       └─ 组件 style={{ backgroundColor: 'var(--adm-card)' }} → 自动变玻璃
```

| `--adm-text` | 主文字 | #f1f5f9 | #111827 |

| `--adm-border` | 分割线/边框 | #334155 | #e5e7eb |

派生工具类（`.adm-card` / `.adm-input` / `.adm-accent` / `.adm-accent-bg` / `.adm-text` / `.adm-border`）与行内变量两种用法并存。

## 3. 面板风格（11 种）

通过 `adminPanelStyle` 设置项切换，写 `data-admin-panel-style` 属性。

| 风格 | 视觉语言 | 关键值 |
|---|---|---|
| solid | 默认扁平 | 基础令牌 |
| glass | 玻璃拟态 | 卡片 rgba(30,41,59,.65)、毛玻璃 blur |
| cyber | 赛博朋克 | 深底 + 青色 #00d4b4 |
| brutalist | 粗野主义 | 3px 硬边框 + 5px 硬阴影，橙色强调 #ea580c |
| gold | 金色奢华 | 米色底 #f5f0e6 + 金 #e6c24a |
| matrix | 矩阵绿 | 黑底 + #00dd3a |
| holo | 全息 | 紫罗兰渐变 |
| mono | 单色红 | 白底 + #e53e3e |
| midnight | 午夜蓝 | 深蓝紫 + indigo |
| obsidian | 黑曜石 | 纯黑 + 白字 |
| noir | 黑色电影 | 灰黑 + 灰白 #94a3b8 |

**强制覆写技巧**（行内样式也能被换肤）：

```css
[data-admin-panel-style="brutalist"] [style*="backgroundColor: var(--adm-card)"],
[data-admin-panel-style="brutalist"] [style*="background-color: var(--adm-card)"] {
  background-color: var(--adm-card) !important;
  border: 3px solid var(--adm-border) !important;
  box-shadow: 5px 5px 0 var(--adm-border) !important;
}
```

## 4. 玻璃分层开关（设置项驱动）

- `glassLayered`：卡片/输入框/侧栏整体半透明化
- `glassSidebar / glassTopbar / glassMenus / glassLists`：局部毛玻璃
- 由 layout 在 `<html>` 上打 `data-glass-*` 属性，CSS 按属性覆写

```tsx
useEffect(() => {
  if (siteSettings?.glassSidebar) document.documentElement.setAttribute('data-glass-sidebar', 'true')
  else document.documentElement.removeAttribute('data-glass-sidebar')
}, [siteSettings?.glassSidebar])
```

## 5. 背景图系统（可选层）

后台支持背景图 + 亮度/对比度/饱和度/模糊/暖度/覆盖层参数：

```tsx
const bgFilter = `brightness(${bgBrightness}%) contrast(${bgContrast}%) saturate(${bgSaturation}%) blur(${bgBlur}px)`
// 三层层叠：背景图(filter) → 黑色/白色 overlay → 暖色调节层
// 侧栏/顶栏在背景图模式下自动半透明 + blur，保持内容可读
```

## 6. 新项目落地清单

1. 复制 `--adm-*` 令牌 + `.adm-*` 工具类
2. 复制 2-3 种面板风格起步（solid + glass + brutalist）
3. 主题切换 = `setAttribute('data-admin-panel-style', style)` + 亮暗两套基础值
4. 规范：**布局用 Tailwind，颜色一律写 var(--adm-*)**，禁止裸色值
5. 强调色 hover 态用 `color-mix(in srgb, var(--adm-accent) X%, transparent)` 派生，避免写死透明度
